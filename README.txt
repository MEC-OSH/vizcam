PUBLISH ON GODADDY (IF USING cPanel WEB HOSTING)
1. Sign in to GoDaddy and open your hosting account -> cPanel -> File Manager.
2. Open public_html for vizcam.me (or the domain's assigned document root). Upload the CONTENTS of this folder (index.html, css/, js/, assets/, .htaccess etc) into public_html.
3. Add vizcam.me to your hosting account and check DNS: set the root (@) A record to the IP ADDRESS provided by YOUR host; set the www CNAME to @ (if supported) or the host-directed target. Do not use guessed IP addresses. Verify both vizcam.me and www.vizcam.me resolve to the host.
4. Issue/enable SSL for BOTH vizcam.me and www.vizcam.me before requiring HTTPS. Set your preferred canonical www domain and direct http/apex traffic to https://www.vizcam.me via your host's redirect facility (where available).
5. Check that https://www.vizcam.me loads the site, assets, gallery, contact emails and WhatsApp quotation flow on desktop and mobile. Update Google Search Console and submit https://www.vizcam.me/sitemap.xml.

If you have only purchased a domain, you ALSO NEED WEB HOSTING to publish this static website. Domain registration itself does not host a site.
If you use GoDaddy Websites + Marketing rather than cPanel Linux hosting, the ZIP cannot usually be directly uploaded as a custom HTML site. Use a host that accepts static HTML files and point the GoDaddy DNS to it.

CUSTOMIZE THE GALLERY
The current images are VIZCAM-styled VECTOR ILLUSTRATIONS, NOT photographs of VIZCAM-completed projects. They are deliberately marked as illustrative. Do not present them as real installation photos.
When you have real project photographs:
1. Add compressed WebP/JPEG project photographs to assets/ (e.g., project-cctv-01.webp).
2. In index.html find <div class="gallery-grid" id="galleryGrid"> and replace each gallery item's img src, data-image, data-title and alt with your photograph and correct project description.
3. Set relevant category: surveillance, network, access, or automation.
4. Update the gallery notice to truthfully reflect the content and, if applicable, describe location/project type without exposing private client details.
5. Use only images you have rights/permission to publish; remove personal details, screens, addresses and faces when necessary.

HOW THE FORM WORKS
